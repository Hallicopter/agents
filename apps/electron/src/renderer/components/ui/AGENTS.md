# Exceptional session-list row windowing

`EntityList.windowing` is opt-in; only SessionList uses this stable row boundary. Row windowing is **enabled only above 200 already-paged logical rows**; smaller lists render all rows with the same keyed wrappers, preserving open menus/focus at 200↔201. This adds a small wrapper/observer overhead to ordinary lists, but does not trigger React updates on ordinary scrolling. Keep the existing 50-session pagination and 100-result search cap; do not split families or virtualize the logical selection/navigation model.

Keep group containers/headers, measured variable row heights, full spacer-backed group extents, selected/keyboard/menu anchors and row accessibility positions. The viewport is an ancestor ref: attach the scroll/ResizeObserver subscription in the passive effect, after that ref mounts. Preserve the first visible row when heights/reorders above it change. Native layout can already clamp scrollTop: restore `savedTop + anchorShift`, never add the shift to the current clamped scrollTop. Refresh the previous OLD logical order from cached full-DOM measurements before activating windowing; use actual newly mounted heights when returning to full small-list mode. Release observers, frames, DOM refs and removed-key caches. Never add a global/session-history cache.
